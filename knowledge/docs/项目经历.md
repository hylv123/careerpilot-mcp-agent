# 项目经历（示例资料，可替换为你的真实项目）

## 项目 1：CareerPilot MCP Agent（进行中）

实习求职助手。输入岗位 JD 和候选人资料，按固定工作流输出岗位分析、能力匹配、定制简历要点和面试题。

- 知识层：把简历.md、项目经历.md、课程笔记.md 切块后用 DashScope `text-embedding-v3` 向量化，写入本地 FAISS。提问「我有哪些项目经历」时应能召回本段内容。
- Agent 层：LangGraph 串联岗位分析、经历检索、工具路由、匹配报告、简历要点、面试题和岗位保存。
- 工具层：接入 3 个 stdio MCP Server（resume / job / document），分别管理经历查询、投递记录和文档生成。
- 可靠性：使用 Pydantic 约束结构化输出，记录节点、模型、工具和 RAG 日志，并提供 20 例离线评测。
- 技术：Python、LangChain、LangGraph、FastMCP、FAISS、SQLite、Loguru。

个人职责：整理知识库文档、实现 `build_index.py` 与 `retrieve.py`、保证检索可返回带来源的真实片段。

## 项目 2：课程作业 RAG 问答小工具

针对课程 PDF 与 Markdown 笔记做最小 RAG：加载文档 → 按中文 300–500 字切块 → embedding → 相似度检索 → 把片段塞进提示词让模型作答。

收获：理解切块过短会丢上下文、过长会引入噪声；中文场景 overlap 约 50 字较稳。该经验直接用到 CareerPilot 的 `RecursiveCharacterTextSplitter(chunk_size=300, chunk_overlap=50)`。

## 项目 3：校园二手书信息登记脚本

用 Python 读取表格，做书名去重与简单分类，导出 Markdown 清单。练习了文件编码（UTF-8）、路径处理和命令行运行习惯，方便后续在 `knowledge/docs/` 下维护多份 md。
