岗位名称：agent开发实习生（AI Agent 开发实习生）
公司：未标注（招聘平台职位详情页）

岗位职责
1. 参与 AI Agent 应用的功能开发，在导师指导下完成模块级需求分析、编码实现与自测。
2. 参与 Agent 工具（Tool / Function Calling）、Skill 插件与提示词（Prompt）的设计、接入与效果调优。
3. 参与多轮会话与上下文管理能力的设计与实现，包括上下文组织、会话状态维护与效果评测。
4. 参与后端服务接口开发与联调，编写单元测试，配合完成问题定位与修复。
5. 参与前端交互页面的对接与基础功能开发，配合完成端到端流程验证。
6. 参与模型效果评测与回归测试，整理测试用例、问题清单与技术文档。
7. 跟踪大模型与 Agent 领域前沿进展，定期输出技术调研并在组内分享。

任职要求
1. 本科及以上在读，计算机、软件工程、人工智能等相关专业，可保证每周 4 天以上、连续 6 月以上的实习时间，28 届和 29 届优先。
2. 掌握 Python 或 TypeScript/JavaScript 至少一门语言，具备基本工程编码能力，了解常用数据结构与算法。
3. 理解 AI Agent 的基本工作原理，能说清「大模型 + 工具 + 执行循环」的链路，了解 ReAct、Plan-and-Execute、Reflection 等常见 Agent 范式中的至少一种。
4. 了解 Function Calling / Tool Use 机制，理解工具定义、参数 Schema 设计、调用结果回填与异常重试的完整流程。
5. 了解提示词工程与上下文管理，能针对具体任务设计系统提示词，理解上下文窗口限制、会话状态维护、长对话截断与摘要等常见处理方式。
6. 接触过至少一种 Agent 开发框架或协议，如 LangChain、LangGraph、AutoGen、CrewAI、MCP（Model Context Protocol），有实际跑通过 Demo 者优先。
7. 熟悉 Git 基本操作与 Linux 常用命令，具备良好的代码规范意识。
8. 具备较强的学习能力与主动性，能独立查阅英文技术文档并快速上手新技术；沟通表达清晰、有责任心，具备良好的文档撰写习惯。
9. 加分项：有 Agent 或多智能体协作项目实践；了解任务规划与分解、Agent 效果评测（任务成功率、工具调用准确率）；有 Web 后端（FastAPI / Node.js）或前端（Vue / React）开发经验；有可展示的开源仓库或技术博客。
