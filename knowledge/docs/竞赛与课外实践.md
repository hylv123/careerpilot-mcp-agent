# 竞赛与课外实践（示例资料，可替换为你的真实经历）

## 算法竞赛

参加校级程序设计竞赛，主力写图论与动态规划题目。
收获：先建模清楚再写代码。比赛中对边界条件的训练，对写业务代码时的健壮性帮助很大——很多线上 bug 本质就是没考虑边界输入。

## 技术博客与开源

维护一个技术博客，记录 RAG、Agent、Docker 的踩坑过程；给一个小型开源库提交过文档修正与补充单元测试。
收获：把事情写清楚的过程本身会暴露理解的漏洞；给别人的项目写测试是学习工程规范最快的方式。

## 协作与沟通

参与过三人小组的课程项目，用 Git 分支协作，写 README 说明如何一键运行。
能阅读英文技术文档与论文摘要；习惯在动手前先把需求与验收标准写下来，避免做完才发现理解偏了。

## 求职准备

把做过的项目整理成可讲清的三段式：要解决什么问题、我做了什么、遇到过什么取舍。
针对目标岗位的技能要求逐条对照，缺哪块就补一个能演示的小项目，而不是只写在简历上。
