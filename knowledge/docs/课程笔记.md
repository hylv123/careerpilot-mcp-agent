# 课程笔记

## 数据结构与算法

掌握数组、链表、哈希表、堆与常见排序。实习项目里检索更接近「向量相似度」而不是手写倒排索引，但切块边界仍要保证一段经历不被拆得过碎。

## 数据库系统

关系模型、主键外键、SQL 查询。CareerPilot 用 SQLite 存投递记录：公司、岗位、状态、时间。知识库本身用 FAISS 文件，不走数据库服务。

## 机器学习导论

理解 embedding 是把文本映射到向量空间，相近语义距离更近。本项目 embedding 模型为阿里云百炼 `text-embedding-v3`，API Key 放在 `.env` 的 `aliQwen-api`。

## Agent 与 RAG 要点

- RAG：先检索再生成，回答要能指向 `docs/` 里的原文。
- Agentic RAG：第一轮高相关结果不足时改写查询，并进行补充检索和结果去重。
- MCP：把「查简历 / 记投递 / 写文档」做成独立工具，Agent 按协议调用，而不是把逻辑全写死在一个脚本里。
